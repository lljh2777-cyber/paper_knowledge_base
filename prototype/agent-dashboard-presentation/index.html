01 / WHY

研究工作的问题，不是信息少，而是上下文断裂

论文、代码、笔记、任务与证据分散在不同工具里，真正昂贵的是反复恢复上下文。

把“找资料、读论文、解释代码、维护笔记”从零散动作，变成一条可追踪执行链。

论文孤岛元数据、全文、结论和图表证据缺少统一深度标记。
脚本孤岛多个脚本属于同一项目，却没有入口、依赖和数据流关系。
知识孤岛新加入的代码节点，无法自动发现缺失的方法与概念枢纽。
维护盲区断链、孤立页、证据深度与导出状态需要持续检查。
AGENT DASHBOARD从信息管理走向研究执行

06 / CODE PRACTICE

像 Notebook 一样逐格练习，但每次运行都可解释

Python / R 单元格采用无状态累计重放：新进程执行前置代码，结果逐格呈现并可保存为知识笔记。

R 练习 · marker expression

values <- c(1.2, 3.8, 2.6, 4.4)
In [2]:
mean(values)
[1] 3
In [3]:
plot(values, type = "b", col = "#27d7e7")

无状态累计重放避免隐藏会话状态，让单元格依赖更清楚。
